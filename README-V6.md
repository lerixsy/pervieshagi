# Первый шаг — обновление v6

## Что изменено

- «Живые цифры» на главной и показатели в обзорах студента, компании и администратора: на телефоне две колонки, читаемые подписи без обрезания. В кабинете компании три показателя размещаются по схеме 2 + 1.
- Каталог вакансий — карточки: одна колонка на телефоне, две на планшете, три на широком экране. Клик по карточке открывает отдельную страницу; ссылка компании и кнопка закладки работают независимо.
- На телефоне дополнительные фильтры свёрнуты под кнопкой «Фильтры», чтобы вакансии были видны раньше. Поиск остаётся на экране.
- Страница вакансии: полное описание, параметры, отклик с необязательным сопроводительным письмом, избранное и переход к компании. На телефоне действия находятся перед описанием.
- Профиль компании: описание, сайт и её открытые вакансии.
- Профиль студента: описание, образование, навыки, опыт, портфолио и разрешённый просмотр резюме. Ссылки добавлены в подбор студентов, отклики, приглашения, чат и меню своего профиля.
- В кабинете компании вакансии тоже отображаются карточками. Форма публикации раскрывается кнопкой «Опубликовать вакансию».
- После входа гость возвращается на выбранную вакансию. Намерение сохранить вакансию или открыть форму отклика сохраняется. Повторный отклик блокируется.
- Предыдущие исправления навигации, центрирование выпадающего меню, порядок «Вакансии → Компаниям → О платформе» и исправления частиц сохранены.

## Как установить в существующий проект

1. Сделайте резервную копию проекта и PostgreSQL.
2. Из архива скопируйте папку `public` и файлы из папки `server` в соответствующие папки своего проекта с заменой. Папки находятся в корне архива.
3. **Обязательно обновите `server/index.js`, а не только HTML/CSS/JS. Новые страницы используют новые API.**
4. Сохраните свой `server/.env`, действующую PostgreSQL и установленные зависимости. Архив не содержит паролей, `.env`, пользовательских баз, `node_modules` и тестовых данных.
5. Остановите предыдущий процесс Node и запустите из папки `server` команду `npm start`. Если зависимости ещё не установлены, сначала выполните `npm ci`. Используется Node.js с поддержкой `--env-file` (20.6+; проверялось на Node 24).
6. Откройте сайт через сервер, например `http://localhost:3000/`. Не запускайте HTML через `file://`. Если процесс управляется PM2 или другой службой, перезапустите её обычным способом.
7. Обновите страницу браузера с очисткой кеша. Стили и приложение имеют новый параметр версии `site6`.

В v6 схема БД и зависимости не менялись относительно предыдущего обновления. Ручные миграции и пересоздание базы не нужны. Не удаляйте данные и не запускайте команды очистки/посева для установки обновления.

## Новые страницы

- `/pages/vacancy.html?id=ID_ВАКАНСИИ`
- `/pages/company-profile.html?id=ID_КОМПАНИИ`
- `/pages/student-profile.html?id=ID_СТУДЕНТА` или `?id=me`

Идентификатор компании — её `user_id`. Для старых вакансий без `company_id` название показывается без ссылки: вымышленный профиль не создаётся. Для перехода к профилю такая вакансия должна принадлежать реальному аккаунту компании.

## Доступ и приватность

- Каталог, активные вакансии и профили одобренных неблокированных компаний доступны гостям.
- Избранное и отклики требуют аккаунта студента; для отклика также нужны подтверждённая почта и заполненный профиль.
- Профили студентов доступны самому студенту, одобренным компаниям и администратору. Другие студенты и гости их не видят.
- В новых профилях не раскрываются email аккаунтов. Доступ к резюме сохраняет прежние ограничения: компания получает его после отклика или принятого приглашения.
- Архивную вакансию видят владелец, администратор и студент, у которого есть связанный отклик/приглашение. Гостям она недоступна.

## Проверка

- 35 проверок реальных Express-маршрутов и middleware авторизации на изолированной тестовой БД.
- 97 браузерных проверок: статистика на ширинах 320, 390, 768 и 1440 px; карточки, мобильные фильтры, переходы, избранное с перезагрузкой, отклик, повторный отклик и ограничения доступа. Ошибок JavaScript не обнаружено.
- Дополнительно проверены клик по площади карточки, независимая ссылка компании и возврат после входа с сохранением намерения добавить в избранное.
- Выполнена визуальная проверка мобильных и настольных страниц и состояний.

Проверки выполнялись локально, с изолированными тестовыми данными. Подключения к вашей рабочей PostgreSQL, отправки реальных писем и выкладки на работающий сайт не было. После установки проверьте сценарий «каталог → вакансия → избранное/отклик → профиль компании» и «кабинет компании → студент» на своих аккаунтах.
