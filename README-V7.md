# Первый шаг — обновление v7

Включает предыдущие исправления v6: мобильную статистику, карточки вакансий, полные страницы вакансий и профили компаний/студентов.

## Новое на главной

### Подвижный «Пример профиля»

Карточка мягко парит, наклоняется вслед за курсором и реагирует на небольшое перетаскивание мышью. Смещение ограничено 24 px, после отпускания карточка возвращается на место. Анимация появления, парение и интерактивный наклон разделены по слоям, поэтому больше не конфликтуют друг с другом.

На телефоне — только лёгкое вертикальное парение: касания не перехватываются, обычная прокрутка остаётся доступной. Выключатель «Плавные анимации» и системное уменьшение движения отключают эти эффекты. Если в браузере анимации ранее отключены, включите их в настройках оформления сайта.

### Частицы немного быстрее

Обычная скорость движения вверх увеличена на 20%. Сохранённое значение ползунка скорости не сбрасывается. Выключатель частиц и прежняя замедленная скорость при отключённых анимациях/системном уменьшении движения сохранены.

### Компании в «Живых цифрах»

Под общей статистикой находится блок «Компании-партнёры». Карточка показывает название, направление и город, количество полученных откликов и открытых вакансий. Вся карточка ведёт в профиль компании.

- Используются реальные записи из PostgreSQL. Демонстрационные компании и цифры в рабочий проект не добавляются.
- Видны только одобренные неблокированные аккаунты компаний. Общий счётчик компаний-партнёров теперь использует то же правило.
- «Полученные отклики» — все записи `student_to_company` на вакансии этой компании, включая архивные вакансии и отклонённые отклики. Приглашения `company_to_student` не включаются.
- Показывается по шесть компаний с кнопкой «Показать ещё компании», в алфавитном порядке. На телефоне карточки идут одной колонкой.
- Список поддерживает состояния загрузки, отсутствия компаний, ошибки и повторной загрузки. Ошибка не подменяется нулевыми показателями.
- Личные данные студентов и email компаний не выдаются: новый API возвращает только публичные поля и агрегированные количества.
- Данные партнёров запрашиваются при открытии главной. Общие показатели платформы сохраняют прежний кеш до 60 секунд.

Новый API: `GET /api/public/companies?offset=0`, ответ `{ items, nextOffset }`. Существующий API отдельной компании `/api/public/companies/:id` сохранён.

## Установка

1. Сделайте резервную копию текущего проекта и PostgreSQL.
2. Скопируйте папки `public` и файлы из `server` из архива в свой проект с заменой.
3. **Обязательно обновите `server/index.js` и перезапустите Node-сервер.** Только замены HTML/CSS/JS недостаточно: у списка партнёров новый API.
4. Сохраните свой `server/.env`, рабочую PostgreSQL и зависимости. В архиве нет паролей, `.env`, пользовательских баз, `node_modules` и тестовых данных.
5. Из папки `server` выполните `npm start`. Если зависимости не установлены — сначала `npm ci`. Нужен Node.js с поддержкой `--env-file` (20.6+). При использовании PM2 или службы перезапустите свой процесс обычным способом.
6. Откройте сайт через работающий сервер, например `http://localhost:3000/`, и обновите страницу с очисткой кеша. HTML использует версию ресурсов `site7`.

В v7 схема БД и зависимости не менялись. Ручные миграции, очистка базы и повторное создание аккаунтов не нужны.

## Проверка

Проверены новые карточки и пагинация, корректность агрегатов, исключение заблокированных/неодобренных компаний, переход в профиль, мобильная вёрстка 320/390/768/1440 px, движение и ограничение перетаскивания, отключение анимаций, пустое состояние и восстановление после ошибки. Ускорение частиц проверено сравнением кадров при одинаковых исходных условиях и сохранённых значениях скорости. Отдельно проверены прежние сценарии вакансий, избранного, откликов и доступа к профилям.

Проверки выполнены локально на изолированных тестовых данных, без подключения к вашей рабочей PostgreSQL, отправки реальной почты или выкладки на работающий сайт. После установки проверьте главную и переходы на своих данных.

Результаты: 48 проверок нового функционала и 132 регрессионные проверки прошли; ошибок JavaScript не обнаружено. Визуально проверены семь настольных/мобильных состояний, включая светлую тему, пустой список и ошибку загрузки.
